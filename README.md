# 🩺 Diário da Saúde

Protótipo visual de uma aplicação de saúde desenvolvido no Figma.

O projeto explora a criação de uma interface para registro e acompanhamento de informações relacionadas à saúde, com foco em organização, clareza e facilidade de uso.

## 🎨 Sobre o projeto

O **Diário da Saúde** é um estudo de UI/UX criado para representar uma possível aplicação de acompanhamento pessoal de saúde.

As telas foram planejadas para explorar:

- Organização de informações;
- Registro de dados de saúde;
- Navegação entre diferentes áreas da aplicação;
- Hierarquia visual;
- Clareza das informações;
- Experiência do usuário;
- Identidade visual relacionada à área da saúde.

> Este projeto consiste em um protótipo visual desenvolvido no Figma e não possui implementação funcional.
